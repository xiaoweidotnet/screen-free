# ScreenFree 视觉系统

## 1. 视觉主题与氛围

ScreenFree 采用“石墨控制台”视觉：接近黑色的深蓝灰工作区、克制的钢蓝强调色和清晰的层级边界。目标是长时间录制与剪辑时低眩光、安静、精确且专业，而不是炫目的霓虹科技感。

## 2. 色彩系统

- 主画布 `#0A0D11`：窗口最底层和时间线外部背景。
- 一级表面 `#0F141A`：工具栏、侧栏和状态栏。
- 二级表面 `#151B22`：检查器卡片、轨道和普通控件。
- 三级表面 `#1B232B`：悬停、浮层和需要抬升的控件。
- 普通边框 `#2D3842`，强调边框 `#445664`。
- 主强调色 `#4E7E9D`，亮强调色 `#6E9FBD`，只用于选中、主按钮、播放头和缩放轨道。
- 视频片段使用低饱和琥珀色，与钢蓝缩放轨道形成稳定区分。
- 红、橙、绿仅承担录制、警告、成功等语义状态。

## 3. 字体系统

使用 macOS 原生 SF Pro，保证中文、数字、快捷键和系统控件的一致可读性。时间码、尺寸和百分比使用 SF Mono 风格的等宽设计；标题采用中等或半粗字重，不使用超大展示标题。

## 4. 组件样式

- 主按钮：钢蓝同色系轻微渐变，白色文字，10px 圆角。
- 次按钮：二级表面加 1px 低对比边框；悬停时仅轻微提亮。
- 选中卡片：钢蓝低透明填充和明确边框，不再使用紫色泛光。
- 时间线：视频片段采用真实画面缩略图，底部固定显示独立的钢蓝真实音频波形；片段左右边缘使用钢蓝裁剪柄，缩放效果保持独立轨道。
- 表单：沿用原生 macOS 交互，在选中和滑杆状态统一使用钢蓝 tint。

## 5. 布局原则

保持现有三栏工作台，不改变功能位置。顶部工具栏、左侧模式栏、中间预览与时间线、右侧检查器保持明确边界；时间线按“时间尺—视频缩略图与波形—缩放效果”组织，内容卡片使用 12–18px 内边距。

## 6. 层级与深度

主要依靠表面明度和细边框建立层级，阴影只用于主按钮、倒计时和系统浮层。禁止大面积彩色泛光、厚重投影和多层玻璃叠加。

## 7. 使用与禁用

- 应使用：单一钢蓝强调、低饱和状态色、清晰的文本对比、稳定的时间线颜色映射。
- 不应使用：紫蓝渐变、粉紫泛光、同屏多个强调色、大面积纯黑导致的层级丢失。
- 用户选择的视频画布、壁纸和导出视觉效果属于内容，不受工作台主题替换影响。

## 8. 窗口适配

在普通窗口和 macOS 全屏中保持相同的表面层级。窗口变窄时优先保护预览、时间线和录制/导出主操作，侧栏与检查器继续通过现有开关收起。

## 9. 交互与动效

按钮按下缩放至 `0.98` 并略微降低亮度；选择和悬停采用短促、柔和的状态过渡。片段选中或悬停时显示左右裁剪柄，可连续拖动并一次撤销；空格切换播放/暂停。时间线播放与缩放动画保持既有产品逻辑，不增加无意义的装饰动画。
