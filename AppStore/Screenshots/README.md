# App Store 截图

Mac App Store 每种本地化需要 1–10 张真实产品截图。可使用的 16:10 尺寸为：

- 1280×800
- 1440×900
- 2560×1600
- 2880×1800

文件格式可以是 PNG 或 JPEG，但不能带 Alpha 通道。`zh-Hans` 和 `en-US` 分别存放两种语言版本。

推荐顺序：

1. 录制来源与麦克风选择
2. 自动跟随鼠标缩放的编辑预览
3. 带真实音频波形的时间线剪辑
4. 画布比例、背景和摄像头布局
5. MP4/GIF 导出设置

截图必须来自真实运行中的 ScreenFree，不得使用与实际功能不一致的概念界面。
