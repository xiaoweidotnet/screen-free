# App 审核备注（简体中文）

ScreenFree 无需登录或测试账号。

核心审核路径：

1. 启动应用并点击“新建录制”。
2. 选择显示器、窗口或拖动框选区域。
3. 麦克风默认启用；如果存在多个输入设备，可在录制设置中选择。
4. 开始录制，完成倒计时后进行几次点击，然后停止录制。
5. 应用进入编辑工作台。可以点击时间线定位、分割片段、调整缩放区间并预览结果。
6. 点击“导出”，选择 MP4、分辨率、帧率及压缩质量后保存文件。

权限用途：

- 屏幕与系统音频录制：只录制用户明确选择的显示器、窗口或区域。
- 麦克风：仅在用户启用麦克风时录制讲解。
- 摄像头：仅在用户选择摄像头画中画时使用。
- 输入监控：用于在录制期间识别点击和支持的长按操作，以创建自动缩放；普通鼠标移动不会触发自动缩放。
- 语音识别：仅在用户主动生成字幕时请求，并强制使用设备端识别。

所有录制与编辑数据均在本机处理。应用不需要网络服务，也不上传用户内容。
