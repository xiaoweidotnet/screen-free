- 全局键盘事件通过 NSEvent.addLocalMonitorForEvents 捕获后封装为自定义 Notification.Name 广播，由订阅方通过 isHandled 标记决定是否拦截事件
- UI 状态集中管理于 EditorStore（@StateObject），视图通过 environment 注入 locale 实现多语言切换
- 异步操作统一使用 Task { await ... } 调用 ScreenFreeCore 暴露的 async API，避免阻塞主线程
- macOS 系统回调（如 applicationShouldTerminateAfterLastWindowClosed）通过 NSApplicationDelegate 子类集中处理生命周期
- 本地化字符串通过 Localization.swift 统一管理，配合 en.lproj/zh-Hans.lproj 中的 Localizable.strings 文件
