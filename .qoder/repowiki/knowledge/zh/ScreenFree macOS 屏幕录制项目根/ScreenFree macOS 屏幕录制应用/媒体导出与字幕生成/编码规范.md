- 每个导出/识别能力都定义一个 `*Error: LocalizedError` 枚举，通过 `errorDescription` 返回用户可读的错误信息。
- 对外 API 采用 `struct` + `async throws` 方法形式，所有耗时 I/O 或系统调用通过 `withCheckedThrowingContinuation` / `await session.export()` 暴露为结构化异步。
- 需要跨线程共享的可变状态（如 `CaptionContinuationState`、`SendableExportSession`）使用 `@unchecked Sendable` + `NSLock` 手动保证并发安全。
- 音视频时间轴统一使用 `CMTime(seconds:, preferredTimescale: 600)` 构造，所有数值参数通过 `.clamped(to:)` 限制到安全区间后再传入系统 API。
