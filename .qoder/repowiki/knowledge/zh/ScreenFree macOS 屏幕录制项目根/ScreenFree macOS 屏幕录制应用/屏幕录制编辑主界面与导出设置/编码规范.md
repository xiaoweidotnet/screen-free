- 所有 View 通过 @ObservedObject var store: EditorStore 注入共享状态，UI 操作统一调用 store 的方法而非直接修改状态。
- 用户输入与显示分离：@State 仅保存本地临时状态（如 draft 区间、拖拽起点），最终结果通过 store 方法提交。
- 颜色与主题统一通过 StudioTheme 常量引用（canvas、accent、surface、timelineClip 等），避免硬编码颜色值。
- 国际化文本使用 LocalizedStringKey 包裹，语言切换通过 store.appLanguage 驱动并配合 .environment(\.locale, ...) 传递。
- 时间轴交互统一使用 DragGesture/MagnificationGesture + TimelineScale.x/time 进行坐标转换，保持像素与时间的双向映射一致性。
- 可选/条件渲染通过 guard 提前返回 + if let 模式匹配，避免深层嵌套的三元表达式。
