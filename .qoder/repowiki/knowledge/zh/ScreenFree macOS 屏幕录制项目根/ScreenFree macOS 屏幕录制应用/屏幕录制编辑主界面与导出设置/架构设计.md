本模块由四个独立的 SwiftUI View 组成，全部通过 `@ObservedObject var store: EditorStore` 共享同一个状态存储（EditorStore），形成单向数据流：View 仅负责展示与用户交互，所有业务逻辑（剪辑、缩放、注释、导出等）委托给 store。
- MainView 是应用根视图，采用 HStack 三栏布局（左侧 panelRail + 中间 preview/playbackBar/TimelineView + 右侧 inspector），并通过 `.sheet` 弹出 ExportSheet 和 MicrophoneSelectionSheet。
- TimelineView 实现多轨道时间轴（clip track / zoom track / privacy track / annotation track），使用 GeometryReader + ScrollView(.horizontal) 配合 TimelineScale 进行时间-像素映射。
- SettingsView 使用 TabView + Form 组织通用设置与权限检查。
- ExportSheet 以分区块（format/frameRate/resolution/compression/destination）形式配置导出参数，通过 store 驱动进度与估计值。
依赖方向：View → EditorStore（单向），不直接依赖 ScreenFreeCore 的业务类型（除 TimelineScale 等 UI 辅助类型外），保持 UI 层薄且可测试。
