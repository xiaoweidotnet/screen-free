- 所有 UI 状态集中在单个 `@MainActor ObservableObject`（`EditorStore`）中，通过 `@Published` 暴露给 SwiftUI 视图，避免分散的状态管理。
- 用户偏好设置统一通过 `UserDefaults.standard.set(..., forKey: "...")` 在属性的 `didSet` 中持久化，读取时在 `init()` 中恢复默认值。
- 错误类型采用 `enum ...: LocalizedError` 形式，实现 `errorDescription` 返回用户可读消息，便于统一展示。
- 国际化文案通过 `L10n.text(key, language: appLanguage, arguments...)` 集中处理，结合 `String.LocalizationValue` 与 `.module` bundle 加载多语言资源。
- 需要跨组件通信的事件通过 `extension Notification.Name` 扩展自定义通知名，由 `NotificationCenter.default.post(name:object:)` 发布，接收方通过 `onReceive(publisher:)` 订阅。
- 外部服务（如 `RecordingEngine`、`VideoExporter`、`ProjectPersistence`）以私有属性注入到 `EditorStore`，保持单一职责与可测试性。
