- 所有 I/O 密集型异步操作通过 `Task.detached(priority: .utility)` 或 `withCheckedThrowingContinuation` 包装，避免阻塞主线程。
- 错误统一通过遵循 `LocalizedError` 的枚举表达（如 `RecordingError`、`RecordingAudioMixError`、`RecordingSegmentMergeError`），并提供中文 `errorDescription`。
- 跨队列共享的可变状态（writer、inputs、firstPresentationTime、finishing 等）一律通过 `NSLock` + `withLock` 扩展进行互斥访问。
- 音频信号处理采用 `CMSampleBuffer` → `UnsafeMutableBufferPointer<Float>` 零拷贝路径，仅在 16bit 整数格式时做 Float↔Int16 转换。
- 可发送性通过 `@unchecked Sendable` 包裹非 Sendable 的底层对象（如 `AVAssetWriter`、`MicrophoneSignalProcessor`），并在内部用锁保证线程安全。
- URL 命名遵循 `Recording-时间戳-UUID.扩展名` / `Mixed-UUID.mp4` / `Merged-UUID.扩展名` 的统一模式，便于后续识别与清理。
