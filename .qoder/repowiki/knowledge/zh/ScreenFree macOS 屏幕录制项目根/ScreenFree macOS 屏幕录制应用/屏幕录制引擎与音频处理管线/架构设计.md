模块以 `RecordingEngine` 为唯一对外入口，封装 `SCStream` + `AVAssetWriter` 的实时写入管线：视频通过 `.screen` 输出，系统音通过 `.audio` 输出，麦克风通过 macOS 15+ 的 `.microphone` 输出；所有样本缓冲在 `captureQueue`（QoS .userInteractive）上串行处理并用 `NSLock` 保护 writer 状态。
- 音频增强由 `MicrophoneSignalProcessor` 提供，支持降噪高通滤波、自动增益控制（AGC）、压缩器与噪声门，配置通过 `MicrophoneEnhancementSettings` 静态预设（`disabled`、`systemAudioLoudness`、`microphoneLoudness`）注入。
- 可选的独立应用音频捕获由私有类 `SelectedApplicationAudioCapture` 完成，生成独立的 m4a 文件后交由 `RecordingAudioMixer` 通过 `AVMutableComposition` + `AVAssetExportSession(passthrough)` 与主视频混流。
- 离线音频分析由 `AudioAnalyzer` 完成，使用 `AVAssetReader` 逐块读取 PCM 并计算 RMS、峰值与按时间对齐的包络线，配合 `AudioWaveformNormalizer` 做自适应静音门控与相对归一化。
- 多段录制合并由 `RecordingSegmentMerger` 顺序拼接多个 mp4/mov 片段，保持音视频轨道索引一致。
- 录制历史由 `RecordingHistoryCatalog` 扫描 `~/Movies/ScreenFree`（或临时目录），仅接受 mp4/mov 并按修改时间降序返回。
依赖方向单向：RecordingEngine → MicrophoneSignalProcessor / RecordingAudioMixer / RecordingSegmentMerger / RecordingHistory；AudioAnalyzer 独立用于回放分析。
