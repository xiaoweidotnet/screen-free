以 ScreenFreeApp.swift 为 @main 入口，使用 NSApplicationDelegateAdaptor(ScreenFreeAppDelegate) 注册全局键盘监听（Escape/Delete/Undo/Redo）并通过 NotificationCenter 广播自定义通知；EditorStore 作为单一状态源被 MainView、SettingsView、ExportSheet 等 UI 组件共享，所有业务逻辑委托给 ScreenFreeCore 框架（录制引擎、媒体导出、字幕生成），本模块仅负责 UI 编排、快捷键路由、项目持久化、本地化和 macOS 系统集成（设备监控、桌面图标控制）。各子模块通过 Store + SwiftUI StateObject 解耦：UI 层只消费 store 的发布状态，录制与导出通过异步 Task 调用 Core 层 API，跨进程事件统一走 Notification.Name 扩展。
