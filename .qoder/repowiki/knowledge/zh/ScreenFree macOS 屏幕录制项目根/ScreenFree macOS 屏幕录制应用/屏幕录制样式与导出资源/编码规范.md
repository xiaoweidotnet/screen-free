- 枚举统一采用 `String, CaseIterable, Codable, Identifiable, Sendable` 四协议组合，并通过 `var id: Self { self }` 满足 `Identifiable`。
- 数值型配置在初始化或访问时通过 `.clamped(to: ...)` 限制到合理范围，保证输入健壮性。
- 可持久化的数据结构同时实现 `Codable + Equatable + Sendable`，并由独立的 `*Persistence` 结构体负责 JSON 读写。
- 计算型工具以 `enum` 静态方法形式暴露（如 `MotionBlurResolver.resolve`、`ZoomMotionResolver.state`、`TimelineWaveformGeometry.bars`），避免实例化开销。
- 预设类通过 `static let` 提供常用默认值（如 `MotionBlurStyle.disabled`、`ZoomMotionStyle.slow/mellow/quick/rapid`、`ResolvedMotionBlur.zero`）。
