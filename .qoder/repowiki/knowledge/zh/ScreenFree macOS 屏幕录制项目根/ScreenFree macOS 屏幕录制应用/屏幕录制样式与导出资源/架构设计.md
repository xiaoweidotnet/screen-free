本模块是纯数据与计算层，不持有状态，所有类型均遵循 `Codable + Equatable + Sendable` 三协议组合，便于跨线程安全序列化与持久化。按职责划分为若干独立文件：
- 画布与背景：`CanvasStyle.swift` 定义 `CanvasBackgroundMode`、`WallpaperPreset`、`ClickEffectPreset`、`CanvasAspectRatio`、`CanvasContentMode`、`CanvasCropGeometry`（含仿射变换与归一化坐标转换）。
- 主题与预设：`StudioTheme.swift` 集中语义化颜色与圆角常量；`StylePreset.swift` 通过 `ScreenFreeStylePreset` 聚合全部样式字段，并提供 `BuiltInStylePreset` 内置预设与 `StylePresetPersistence` JSON 持久化。
- 摄像头覆盖层：`CameraOverlayStyle.swift` 提供 `CameraPosition` 与 `CameraOverlayStyle`。
- 光标艺术：`CursorArtwork.swift` 用 CoreGraphics 路径绘制箭头与指针两种光标图像。
- 动效：`MotionBlur.swift` 基于采样间隔计算屏幕/光标运动模糊半径；`ZoomMotion.swift` 实现缩放关键帧插值、缓动曲线（含自定义 CubicBezier）与自动缩放策略。
- 音频与波形：`RecordedAudioLayout.swift` 根据系统/麦克风录制模式推导轨道布局与增益；`TimelineWaveformGeometry.swift` 将采样序列映射为时间轴波形柱条。
- 导出：`ExportOptions.swift` 封装帧率、分辨率、质量、格式、剪贴板写入与文件大小估算。
依赖方向单向指向 `ScreenFreeCore`（用于 `TimelineProject`、`ZoomEvent`、`MouseClick`、`TimelineClip` 等核心类型），本模块不反向依赖上层 UI 或业务逻辑。
