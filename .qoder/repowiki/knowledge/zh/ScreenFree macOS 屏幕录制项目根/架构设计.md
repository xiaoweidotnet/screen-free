Package.swift 作为唯一依赖声明入口，定义两个产品：可执行目标 ScreenFree（SwiftUI 应用）与库目标 ScreenFreeCore（时间线模型与转场计算），并通过 dependencies 建立单向依赖关系——应用层依赖核心库，测试目标分别依赖对应实现。顶层 scripts/ 提供本地运行、App Store 发布包和 DMG 打包三个 Bash 流程，appstore_assets/ 集中管理商店元数据与图标资源，tests/ 通过 XCTest 覆盖 Core 与 Media 功能。各子模块通过 SPM 目标边界隔离，共享契约由 Package.swift 中的 target 与 dependency 声明强制约束。
