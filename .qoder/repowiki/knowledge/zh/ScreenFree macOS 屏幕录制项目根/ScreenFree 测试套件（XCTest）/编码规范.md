- 测试类统一继承 `XCTestCase` 并以 `final class XxxTests` 命名，测试方法以 `func testXxx()` 形式声明
- 浮点比较一律使用 `accuracy:` 参数（如 `0.001`、`0.000_001`）配合 `XCTAssertEqual` 而非精确相等
- 涉及文件系统操作的测试通过 `temporaryDirectory.appendingPathComponent(UUID().uuidString, isDirectory: true)` 创建隔离目录，并用 `defer { try? FileManager.default.removeItem(at: directory) }` 确保清理
- 对 JSON 序列化的测试同时覆盖当前格式与移除若干字段的「legacy」格式，验证向前/向后兼容性
- 视频帧像素对比通过自定义 `rgbaPixels(from:)` 提取 RGBA 数组后计算差值总和，用阈值断言渲染差异
- 异步测试统一使用 `async throws` 签名并通过 `try await` 调用导出与分析 API
