- 所有面向用户的文本按 locale 拆分为独立 Markdown 文件（如 `en-US.md`、`zh-Hans.md`），便于双语文档维护。
- 图片资源严格遵循 Apple 规格命名与尺寸约定（如 `icon_16x16.png`、`icon_16x16@2x.png`、`AppIcon-1024.png`），不得自定义命名。
- 需要人工替换的占位信息使用 `[REPLACE WITH ...]` 标记并在 README 中集中列出，避免硬编码敏感值。
- 提交前检查项以 Markdown 复选框形式记录在 `SUBMISSION_CHECKLIST.md`，已完成的条目打勾，未完成的保持空白以便追踪。
